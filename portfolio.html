Modul & Fitur Unggulan

Fitur Komprehensif Berorientasi Pengguna

Dirancang khusus untuk mendukung operasional sekolah secara terintegrasi antara Guru, Siswa, dan Administrator.

⚡

QR Code Dinamis Berbatas Waktu

QR code memperbarui token setiap 20 detik dengan fungsi kriptografi. Siswa yang memotret layar untuk temannya tidak dapat menitipkan absen karena token segera kedaluwarsa.

📱

PWA & Hybrid Android APK

Dapat diinstal langsung di laptop via peramban web modern, serta siap dikompilasi menjadi paket aplikasi Android (APK) asli dengan Capacitor 8 tanpa modifikasi kode ulang.

🛡️

Koreksi Manual & Audit Log

Guru berwenang mengoreksi status siswa (hadir, terlambat, sakit, izin) dengan kewajiban mengisi alasan resmi yang tersimpan di rekam jejak audit log yang tidak dapat dihapus.

⏱️

Klasifikasi Waktu Otomatis

Algoritma sistem menghitung detik kedatangan siswa secara presisi. Kehadiran sebelum batas toleransi dicatat "Hadir", sedangkan setelah toleransi otomatis diklasifikasikan "Terlambat".

📊

Rekapitulasi Excel & CSV

Administrator dapat mengunduh seluruh riwayat absensi kelas per periode (harian, mingguan, bulanan) dengan format laporan terstruktur siap cetak ke dinas pendidikan.

📁

Offline Cache Resilience

Mekanisme penyimpanan ganda (Firestore Cloud + LocalStorage Sinkron) menjamin siswa tetap dapat melihat riwayat dan jadwal ketika jaringan WiFi sekolah sedang mengalami gangguan.

Fondasi Teknologi

Arsitektur Rekayasa Perangkat Lunak

Dibangun dengan struktur bersih yang memisahkan lapisan visual, logika bisnis, dan integrasi perangkat keras.

🎨 Visual Design System

Pure CSS3 Tokens, font Inter, dan tata letak responsif murni. Desain rapi tanpa kebergantungan komponen template pihak ketiga yang kaku.

📷 WebRTC Video Engine

Akses perangkat keras kamera menggunakan MediaStream API dengan decoder jsQR canvas dan fallback upload gambar instan.

🔐 Kriptografi Token Hash

Enkripsi payload JSON yang mencakup identifier sesi unik, masa berlaku UNIX, dan kunci validasi kelas.

📦 Cloud & Hybrid Build

Capacitor 8 bridge untuk Android Native serta GitHub Actions otomatis untuk kompilasi APK mandiri di cloud.

Portofolio Pengembang & Informasi Proyek
Aplikasi HadirKu dikembangkan sebagai proyek akademik rekayasa perangkat lunak web sekolah. Sesuai arahan dosen pembimbing, sistem ini menonjolkan kerapihan visual antarmuka (clean CSS layout), arsitektur aplikasi dinamis (real-time state & reactive countdown), serta fungsionalitas presensi QR code yang teruji bebas dari celah titip absen.
